# Task 4: Advanced AI Technique

## Selected Technique

MLflow was selected because it provides experiment tracking and supports reproducible machine-learning workflows.

## Implementation

MLflow was configured to track model experiments and evaluation metrics.

The following models were recorded:

- Linear Regression
- Random Forest Regressor
- Neural Network

Metrics tracked:

- MAE
- R²

## Value Added

MLflow enables systematic comparison of models and improves experiment reproducibility.

It provides a centralised eniroment for managing machine-learning runs.

## Limitations

MLflow improves experiment management but does not directly improve predicitive performance.

Additional tooling and infrastructure are required for large-scale deployments.
